# 界面设计标准

## 菜单栏与面板

- 使用容易辨认的剪贴板图标，提供「剪贴板历史」无障碍名称。菜单栏图标和全局快捷键都打开同一个面板。
- 在 Finder 打开或再次打开应用时，直接显示历史窗口。关闭窗口后，仍可从菜单栏打开历史。一次只显示一个历史界面。
- 历史窗口和菜单栏面板左下角都提供「设置」。加入搜索后，在历史列表上方显示搜索框，打开面板时让搜索框可立即输入。按 `Esc` 关闭面板。
- 采用 macOS 原生控件、系统字体和语义颜色。支持浅色、深色和键盘焦点提示。

## 历史卡片

- 文字卡片最多展示几行预览，图片卡片保持缩略图比例。所有卡片的复制时间放在一致的位置。
- 置顶卡片排在最前面，并带有可识别的置顶图标。置顶、取消置顶和删除有独立按钮，并提供文字提示及无障碍名称。
- 取消置顶时，如果这条记录已过保留期限，明确告知确认后会立即删除，并提供「保留置顶」选项。
- 按下卡片的复制区域或用键盘激活时，成功后给出「已复制」反馈，历史窗口或面板保持打开。失败时提示可以重试。置顶和删除按钮各自只执行对应操作。

## 搜索、设置和状态

- 「在屏幕顶部显示剪贴板图标」放在应用设置窗口，说明点按顶部图标可以打开历史。
- 搜索框占位提示为「搜索文字记录」。暂无任何记录时显示「复制文字或图片后，记录会出现在这里」。有历史但搜索无结果时显示「没有匹配的文字记录」。
- 设置使用单选项显示 1 天、3 天、5 天，并说明置顶记录会一直保留，可手动删除。缩短保留时间会清理已有记录时，先显示确认。
- 设置里的「删除前确认」默认开启。点垃圾桶时，确认只删除选中的记录，取消时保留该记录。
- 若系统未允许读取或本地存储出错，在面板中用一句短提示说明当前状态和处理方式。
