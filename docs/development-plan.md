# 分阶段开发计划

每次开发只推进当前阶段里一个可单独验收的任务。完成后记录结果和待办，再从当前阶段的剩余事项或下一阶段选择任务。

| 阶段 | 开发内容 | 进入下一阶段的条件 |
| --- | --- | --- |
| 0. 建立项目规范 | 整理需求、技术方案、设计准则、阶段计划和日志流程。 | 标准文件路径可用，日志可生成，定时任务已验证或已记录待解决的启用条件。 |
| 1. 验证基本入口 | 检查 Xcode 和可用 SDK，创建最小 macOS 项目，先跑通 Finder 启动、菜单栏图标与空面板，再验证全局快捷键。 | 从 Finder 打开和再次打开实际应用包均能看到历史窗口。菜单栏图标可用时快捷键打开同一面板，图标没有空间显示时快捷键打开历史窗口。 |
| 2. 跑通文字 | 实现文字记录、本地存储、列表展示和从卡片再次复制。 | 在文本编辑中复制中文和多行文字，历史会出现记录，重启后仍在，点击后能完整粘贴，应用自身写回不会产生额外记录。检查系统允许和拒绝读取的表现。 |
| 3. 加入图片 | 支持原生剪贴板图片的持久化、缩略图与复制。 | 用截图、预览等来源实测；重启后图片仍可查看并粘贴，列表可流畅查看，单张损坏或无效数据不会阻断其他记录。 |
| 4. 管理历史 | 依次实现置顶和删除、保留期限、文字搜索。每项单独验证。 | 分别验证 1、3、5 天与临界时刻，过期置顶记录仍可手动删除，清理不会删掉置顶内容，搜索匹配完整文字并正确显示空状态。 |
| 5. 试用交付 | 检查浅色、深色、键盘操作和权限提示，跑通复制、重启、搜索和再次粘贴的完整流程，准备本机试用版本。 | 真实 Mac 上可以按使用说明启动与退出。记录已测试的 macOS 版本、验证结果和已知限制。 |

发布前，使用隔离的测试历史覆盖重启、清理到期边界、修改期限、置顶后过期、取消置顶以及本地写入失败。用合成数据做样例。
