# 第一版需求与验收

在一台 Mac 上保存近期复制过的文字和图片。用户可以从菜单栏打开历史，找到之前的内容并再次粘贴。

| 功能 | 第一版行为和验收条件 |
| --- | --- |
| 打开历史 | 点击 Mac 菜单栏图标或按全局快捷键打开同一个历史面板。建议默认使用 `⌃⇧V`（Control + Shift + V），开发阶段验证冲突。 |
| 自动记录 | 软件运行且获准读取系统剪贴板时，复制纯文本或原生剪贴板图片会生成对应卡片。退出后重新打开，之前保存且未过期的记录仍可用。 |
| 浏览历史 | 置顶记录显示在列表顶部，两组内部各按原复制时间降序。文字有预览，图片有缩略图，所有卡片显示复制时间。 |
| 再次粘贴 | 点击卡片即可把完整内容放回剪贴板，卡片提示「已复制」，历史界面保持打开。用户到目标软件按 `⌘V` 即可粘贴。这次操作保留原卡片和原复制时间。 |
| 置顶与删除 | 用户可以置顶、取消置顶或手动删除任何卡片。设置中默认开启「删除前确认」。卡片处于置顶状态时一直保留，自动清理始终跳过它。取消已过期记录的置顶时，确认后才删除。 |
| 搜索 | 输入关键词即可按完整文字内容筛选，支持中文和多行文字。清空关键词重新显示全部记录。第一版只搜索文字记录。 |
| 保存期限 | 设置提供 1 天、3 天、5 天，默认 3 天。从原复制时间按每 24 小时计算，达到期限的未置顶记录自动清理。缩短期限将立即清理现有记录时，先征求用户确认。 |
| 本机存储 | 内容和设置留在本机。第一版的范围是纯文本和剪贴板提供的图片数据，图片识字、文件管理、云同步和账号留待后续讨论。 |

默认快捷键、默认期限、到期后取消置顶的处理和最早支持的 macOS 版本属于方案细节。进入相关阶段前根据实测确认。
