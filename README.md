# -# 剪贴板历史

一个用 Swift 编写、由 Codex 协助开发的原生 macOS 菜单栏工具。它会记录应用运行期间新复制的文字和图片，方便你找回之前复制过的内容。

## 目前能做什么

- 从菜单栏图标或 `Control + Shift + V` 打开历史。
- 按复制时间查看文字和图片，常用记录可以置顶。
- 点一条记录即可重新复制，历史面板保持打开。回到目标应用按 `⌘V` 即可粘贴。
- 可设置保留 1、3 或 5 天，默认 3 天。置顶记录会继续保留。
- 可以删除单条记录，默认开启删除前确认。

剪贴板历史保存在本机。

## 在 Mac 上运行

需要安装支持 Swift 6 的 Xcode 命令行工具。项目的构建目标是 macOS 14 或更高版本，目前已在 Apple 芯片 Mac 上验证。

在项目目录中运行：

```sh
sh scripts/build-app.sh
```

构建后，在 Finder 中双击 `build/剪贴板历史.app`。如果 macOS 提示剪贴板读取权限，请选择允许。
